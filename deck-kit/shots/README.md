# Screenshots

Real product screenshots used by the deck. Generated by the capture workflow
(`deck-kit/workflow.yml` → copy to `.github/workflows/`) or locally:

```bash
cd deck-kit/capture && npm install && npx playwright install chromium && npm run shots
```

File names must match the `screen.name` values in
[`../capture/capture.config.json`](../capture/capture.config.json) and the
`shot` values in [`../deck.config.js`](../deck.config.js). Until a PNG exists, the
deck shows a labeled placeholder for that screen — so it always renders.
